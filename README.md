# Sam, Barman

A simple promotional website built during my early React learning journey, focused on interactive UI patterns and component-based development.

## Overview

Sam, Barman is a fictional bartender website designed to showcase services, personal branding, and contact information through a modern single-page experience.

The project was created as one of my first practical React applications and served as an opportunity to move beyond static pages by experimenting with interactive elements and user-driven interfaces.

## Tech Stack

* React
* JavaScript
* CSS
* useRef
* Responsive Design

## Features

* Single-page promotional website
* Infinite scrolling content sections
* Drag-to-scroll interactions
* Responsive layout
* Contact section
* Social media integration

## Why I Built It

The goal was to gain practical experience with React by building a complete website from scratch rather than isolated exercises.

This project allowed me to explore how reusable components, state management, and DOM references can be combined to create more engaging user experiences.

## Key Learnings

* Component-based UI development
* Managing DOM interactions with `useRef`
* Implementing drag-to-scroll interfaces
* Creating infinite scrolling content sections
* Building responsive layouts with React
* Structuring larger single-page applications

## Technical Highlights

### Drag Interactions

Implemented horizontal drag behavior using React refs and direct DOM manipulation, providing a smoother and more interactive browsing experience.

### Infinite Scrolling Sections

Built continuously scrolling ingredient and category rows to create visual movement throughout the page while maintaining a lightweight implementation.

### React Fundamentals

The project helped reinforce core React concepts such as component composition, props, state management, and lifecycle awareness.

## Historical Context

This project was built during the early stages of my frontend development journey.

While the implementation is relatively simple by today's standards, it represents an important milestone in moving from static websites to interactive React applications and experimenting with more advanced user interactions.
